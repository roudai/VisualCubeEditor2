# 練習機能の仕様

MegaminxImageEditor の `reference/PRACTICE_SPEC.md` を VisualCube Editor（3x3x3）用に書き直したもの。コードと食い違うときはコードを正とする。

## 目的
スクランブルで手元のキューブを崩し、解くタイムを測って、PLL・OLL を覚えているかを確かめる。
目安の時間（しきい値）以内に解けたケースは自動で「習得済み」、超えた・解けなかったケースは「練習中」にする。

## データ
- 元データ：`data/pll/scrambles.json`・`data/oll/scrambles.json`（`{ ケース名: [スクランブル 20 本] }`。キーは `algs_info.json` の `name`）
- 生成：`node tools/gen-scrambles.js`（json を作る。ケースの状態にランダムな AUF を足したものを `js/cube-solver.js` で解き、その逆手順をスクランブルにする。種は固定）
  → `node tools/build-scrambles.js`（`js/pll-scrambles.js`・`js/oll-scrambles.js` = `window.PLL_SCRAMBLES = { "Aa": [...] }` を作る）
  - 各スクランブルで崩した状態が、そのケースになるかを確かめる（`js/case-check.js` の `fitSetup`。`test/scrambles.test.js` が全件を確かめる）
  - PLL・OLL のデータ（`algs_info.json`）を変えたら作り直す
  - 練習ページだけが読み込む（エディタ・一覧は重くならない）

## 練習ページ（`practice.html`・`js/practice.js`・`css/practice.css`）
- 設定
  - 種類：PLL / OLL / 通し（見出し「練習」の横に置き、下の設定の行を1行に収める）
  - グループ：「すべてのグループ」または選んだグループ（例：`Dot, Square`）。押すとグループのボタンが並ぶ欄が開き、押したグループだけを出題する（1つも選んでいなければすべて。「選択を解除」で戻す）。グループのボタンにマウスを乗せると説明とケースの数が出る。PLL・OLL それぞれで覚えておく
  - 対象：未習得 / 練習中 / 習得済み / すべて（それぞれ件数付き。グループで絞った中の件数）
  - 習得の目安：2秒 / 3秒 / 5秒 / 8秒（既定は 3秒）、または入力欄に数値（1〜120 秒）。入力した秒数はボタンには足さず、入力欄を強調する
  - 「グループ順 / 覚える順」の切り替えと、OLL の範囲（No Dot / Dot）は無い（Megaminx 版にだけある。覚える順は、`data/<set>/learn_order.json` を置いてデータを作り直せば出る）
- 出題：対象に当てはまるケースからランダム（直前と同じケースは避ける）、そのケースのスクランブル 20 本からランダムに選び、**そのまま出す**
  （ランダムな AUF 込みで作ってあるので、出題のときに AUF は足さない）。ケースの名前と画像は解き終わるまで出さない。対象が0件なら「対象のケースがありません」
- タイマー
  - スペースキーを押した瞬間にスタート（画面ではタイマーの数字をタップした瞬間）。計測中は数字を青にする
  - 計測中は何かのキー（画面ではどこかをタップ）でストップ。Esc は中止（記録せず、同じスクランブルのまま）
  - 計測中に「スキップ」を押すと、タイムを記録せずに次の問題へ（習得済みにはならない）。「解けなかった」を押すと、タイムを記録せずに練習中にする
  - キーの押しっぱなしによる繰り返しは無視する（スタートしたスペースを押し続けても止まらない）
  - 計測中もスクランブルは出したまま（通しも同じ）。操作の説明とヒントは隠す。止めたタップでそのままボタンを押さないよう、止めてから 0.4 秒はボタンを無視する
  - 止めたあと（「解けなかった」も）はタイムを 0.00 に戻さず、次の計測が始まるまで出したままにする（「解けなかった」は `DNF`）。
    タイマーのすぐ上に、解いたケース（`PLL Aa`・`OLL 27`）を出す。この行は空のときも高さを取っておき、出し入れでタイマーが動かないようにする。
    結果の「取り消す」を押したら 0.00 に戻し、ケースの名前も消す。「スキップ」・設定の変更でも 0.00 に戻す
- **ヒント**（スタート前だけ押せる）：ケースの名前と、解く手順（自分の手順があればそれ）の最初の3手を出す。もう一度押す（ボタンは「ヒントを隠す」になる）と消す。ヒントを見た問題は、目安以内で解けても練習中にし、タイムを最近の記録に入れない
- 判定（`js/progress.js` の `judge`）：目安以内 → 習得済み、超えた → 練習中。「解けなかった」→ 練習中（タイムは DNF）。「スキップ」は記録せず次へ
- 結果：タイム、判定（例：「✓ 習得済み（3秒以内）」）、**取り消す**（直前の判定とタイムを戻す）、ケースの画像・名前・手順（自分の手順があればそれ）、そのケースの最近のベスト・平均
- 直近の記録：このページを開いてからの結果を最大12件（ケース名とタイム、習得済みは緑・練習中は琥珀）
- 判定したら次の問題（スクランブル）をすぐ出す（結果は前の問題のもの）
- 画像は上面図（`js/cube-draw.js`。srVisualizer の Plan 表示）。配色は一覧と同じ（`Progress.displaySettings`）

## 保存（`js/store.js` 経由。ログイン中はクラウドにも）
- 覚えた度：一覧と同じ `progress` を書き換える（`js/progress.js`。一覧と練習で共通）
- `practice`：`{ set, filter, threshold, groups: { pll: ["Edges only"], oll: [] }, stats: { 記録のページの表示 }, log: [日時付きの記録], times: { pll: { "Aa": [最近のタイム(秒) 新しい順 最大10件] }, oll: {…} }, full: { 通しの設定と記録 } }`
- URL `?set=oll&filter=new` で設定の初期値を指定できる（その値で保存し直す）。`&groups=Dot,Square` で出題するグループ、`&case=Aa` で最初の1問のケース

## ほかのページ
- 全ページのナビバーに「練習 / Practice」
- PLL・OLL 一覧の上部に **練習する** ボタン：今の絞り込み・選んだグループのまま `/practice?set=…&filter=…&groups=…` を開く
  - `groups` は一覧で選んだグループ。空ならすべて。練習ページはその選択で保存し直す（一覧で何も選んでいなければ、練習ページの選択も外れる）

## 記録（`stats.html`・`js/stats.js`・`css/stats.css`）
- 判定のたびに `practice.log` に `{ at: 日時(ms), set, name, sec(null=解けなかった), status, hint }` を足す（新しい順、PLL と OLL を合わせて最大 2000 件。「取り消す」でその1件も消す）。集計は `js/progress.js` の `addLog`・`summarize`・`daily`・`perCase`
- ナビバーの「記録 / Stats」、練習ページの「すべての記録を見る」（`/stats?set=oll` のように今の種類を渡す）から開く
- 種類（PLL / OLL / 通し）・期間（7日 / 30日 / すべて）で絞る（`practice.stats` に保存）
- 集計のカード：練習回数、平均（とベスト）、解けなかった回数、習得済みの数（今の覚えた度）
- 日ごとの練習：棒＝回数、線＝平均タイム（練習した日だけを結ぶ）。期間が「すべて」のときは直近 90 日。棒にマウスを乗せると日付・回数・平均。ライブラリを使わず SVG で描く
- ケースごとの表：画像・ケース・グループ・覚えた度・回数（解けなかった回数）・ベスト・平均・最後に練習した日。既定は平均の遅い順（苦手なケースが上）。見出しを押すと並べ替え。ケースを押すと、そのケースを最初に出題する練習ページ（`/practice?set=…&case=…`）を開く
- 「CSV で書き出す」：期間内の記録（`visualcube-<pll|oll>-practice.csv`。date, set, case, time（DNF）, status, hint）
- 別のタブで練習したら、記録のページにも反映する（storage イベント）

## 通し（Full solve）
- 練習ページの種類「PLL | OLL | 通し」の「通し」で、3x3x3 を通しで解くタイムを測る。記録のページにも「通し」
- スクランブル（`js/wca-scramble.js`・`js/cube-solver.js`）：WCA と同じ random-state。一様ランダムな状態を作り、two-phase ソルバで解いた逆手順を出す（1 行、20 手前後。2 手未満で揃う状態は作り直す）
  - 次の 1 本を先に作っておく（`WcaScramble.prepare`）。ページを開いて最初の 1 本だけは、ソルバの表の準備（PC の Chrome で約 0.4 秒）が終わるまで「スクランブルを作成中…」と出し、タイマーを押せなくする。2 本目からは待たない（1 本 平均 約 10 ms）
  - 幅が足りなければ手の区切りで折り返す（`css/common.css` の `.scramble-line`）
- 設定：インスペクション（15秒）あり / なし。対象・グループ・目安・ヒントは出さない
- タイマー
  - **長押しして離すとスタート**：スペース（スマホはタイマー）を 0.3 秒押すと準備完了（数字が赤 → 緑）、離した瞬間にスタート。短く押しただけでは始まらない。ストップは任意のキー・タップ（PLL・OLL と同じ）
  - インスペクションあり：スペース（タップ）で 15 秒のカウントダウン（残り秒数）。8 秒・12 秒で色が変わる。カウントダウン中にスペースを長押しして離すと計測開始。15 秒を超えて 17 秒までに始めたら +2、17 秒を超えたら DNF（WCA の規則どおり）。インスペクション中の Esc は中止
  - 止めたあとはタイムを 0.00 に戻さず、次のインスペクション・計測が始まるまで出したままにする（+2 は `12.10+`、DNF は `DNF`。結果でペナルティを変えたら表示も変え、削除したら 0.00 に戻す）。次のスクランブルはすぐに出す
  - 「解けなかった」「スキップ」「ヒント」のボタンは出さない。解けなかったときは、結果の OK / +2 / DNF で DNF を付ける
- 結果：タイム（+2 なら `12.10+`）、**OK / +2 / DNF** の切り替え（あとから変えられる）、**削除**、スクランブル
- 直近の記録の上に、今の ao5・ao12、ベスト（単発・ao5・ao12）。直近の記録は保存してある最新 12 件
- 平均（`js/progress.js`）：`average(recs, n)` は直近 n 回から最速と最遅を除いた平均。DNF は最遅とみなし、DNF が2つ以上なら DNF。足りなければ「–」。`bestAverage`・`bestSingle`・`effectiveTime`（+2 込みのタイム）
- 保存：`practice.full = { inspection, log: [{ at, sec, penalty: '' | '+2' | 'DNF', s }] }`（新しい順、最大 2000 件。ログイン中はアカウントにも）。覚えた度は変えない
  - `s` はスクランブルの短い形：1 手 = 1 文字（`U U2 U' R R2 R' F F2 F' D D2 D' L L2 L' B B2 B'` の順に `A`〜`R`。`WcaScramble.encode`・`decode`）。
    1件 約 75 文字で、2000 件でも約 15 万文字（アカウントの保存の上限 50 万文字に、PLL・OLL の記録 2000 件（約 18 万文字）と合わせて収まる）
  - 18 通り以外の記号を含むスクランブルは全文（`scramble`）で保存する逃げ道がある（今の生成では起きない）。表示は `WcaScramble.textOf`（どちらの形も読める）
- 記録の一覧のスマホ表示（幅 576px 未満）：横にスクロールしないよう、1件を2段にまとめる（1段目：チェック・タイム・見る・×、2段目：日時・ao5・ao12）。見出しの行は隠し、「すべて選ぶ」は削除のバーに出す
- 記録の削除（記録のページの「通し」の記録の一覧）
  - 個別：各行の右の × で、その1件をすぐに削除する
  - 一括：各行の左のチェックで選び（見出しのチェックで表示中をすべて選ぶ・外す）、「選択した記録を削除（n）」→「n 件の記録を削除しますか？」→「削除する」で削除する。期間を変えて見えなくなった記録は選択から外す
  - どちらも削除のあとに「n 件の記録を削除しました。 元に戻す」を出す。元に戻すと、削除したあとに増えた記録も残したまま、消した記録を日時の順に戻す
  - 練習ページの結果の「削除」（直前の1件）は元に戻せない
- 記録のページ（通し）：カード（回数と DNF の数、ベスト、ベスト ao5（今の ao5）、ベスト ao12（今の ao12））、日ごとのグラフ（平均は DNF を除く）、記録の一覧（日時・タイム・その時点の ao5・ao12・スクランブルは「見る」で、その行のすぐ下に表の幅いっぱいの行として開く。「閉じる」で閉じる）、CSV（`visualcube-full-solves.csv`。date, time, penalty, result, scramble）
- タイムの表示：60 秒以上は分表記（例：`1:05.23`。`js/progress.js` の `formatTime`）。練習ページのタイマー・結果・直近の記録・ao5/ao12、記録のページのカード・表・グラフの目盛りで使う（CSV の秒の列は秒のまま）

## Megaminx 版（移植元）との違い
- スクランブル：Pochmann 記法 7 行 → random-state の 1 行。短い形は 13 文字固定 → 1 手 1 文字（可変長）
- ケース用スクランブルに出題時の AUF を足さない（`Progress.wrapAuf` は使っていない。関数とテストは残してある）
- 習得の目安：5 / 8 / 10 / 15 秒（既定 8）→ 2 / 3 / 5 / 8 秒（既定 3）
- OLL の範囲（No Dot / Dot）と PLL の覚える順が無い
- 以前の形の通しの記録を短い形に直す処理は無い（新しいアプリなので古い記録が無い）
- 画像は canvas ではなく SVG（srVisualizer）
